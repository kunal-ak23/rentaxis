# Palm Ridge Properties: fictional accounting demo brand

**Palm Ridge Properties L.L.C. is not a real company.** It is the organisation the accounting
tutorial track (`.superpowers/accounting-tutorials.md`, ids 38–46 plus the refreshed accounting
tutorials) records against, seeded by `tutorials/seed/seed_palm_ridge.py` on the local
recording stack only. Everything here was invented for the demo: the name, the mark, the stamp
and its licence number. The stamp says "DEMO · NOT VALID".

| File | Use |
|---|---|
| `logo-mark.svg`, `logo-mark.png` | round mark (palm over a ridge line). This is the org logo: the header shows it as a 32 px round avatar, and receipts, tax invoices and contract PDFs print it |
| `stamp.svg`, `stamp.png` | round company stamp for `stampImageUrl` |
| `render.mjs` | re-renders the PNGs from the SVGs with headless Chromium (`node tutorials/brand/palm-ridge/render.mjs`) |
