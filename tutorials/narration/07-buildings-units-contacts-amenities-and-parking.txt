This tutorial shows the operational inventory inside a property: buildings, units, contacts, amenities, and parking. We are using the prepared RentAxis Tutorial Studio tenant, so the recording opens each creation form without saving another production record.

Start on the prepared residence overview. It is the property boundary for buildings, units, contacts, amenities, parking, leases, and assigned staff. Open Buildings and choose Add Building. The form captures bilingual names and the floor count. In a real workflow, enter approved values, save once, reopen the record, and verify the floor information before moving on.

Open Units and choose Add Unit. Enter a unit number, type, size, expected rent, and building. Vacancy status affects later leasing and listing workflows, while occupied status should correspond to an active tenancy. Review the currency and rent values carefully before saving in a real onboarding.

Return to the overview and choose Add Contact. Select the category, then enter an approved operations or emergency name, phone, email, address, and notes. Contacts are property-directory records, not application login accounts; do not add personal details that are not approved for the tenant directory.

Open Amenities and choose Add Amenity. The form supports English and Arabic names, a description, Bookable status, and tower scope. In a real workflow, use prepared operating rules and capacity values so the renter request flow sees the correct availability. Finally, open Parking and choose Add Spot. Provide the spot number, level, coverage, and optional tower scope. Mark parking assignable only when residents are allowed to request it.

For every inventory type, save only after a top-to-bottom review and then reopen the record to confirm persistence. Prefer deactivation when an item has historical operations; reserve deletion for an erroneous synthetic record with no dependencies. These inventory boundaries are what later support leasing, facility requests, parking allocation, listings, and property operations.
