This tutorial follows one parking request from availability to approval and release. Begin as the Tenant Admin in RentAxis Tutorial Studio. Open the prepared property, select Parking, and confirm that spot TUTORIAL-B2-18 is active, available, and assigned to the correct property before a resident requests it.

Switch to the prepared Ahmed Hassan renter account and open Facilities and Parking. Check the property name, level, coverage, and Available status. Select Request for TUTORIAL-B2-18. RentAxis selects the resident’s active unit. Enter the prepared future date and a short operational note, then review the request before submitting.

Select Submit Request once. The dialog closes and the new row appears in My Requests with a Pending status. Pending means the request exists, but the parking spot has not been allocated. Do not submit repeatedly if the response is slow; wait for the refreshed status.

Now switch back to the Tenant Admin and open Booking Requests. Keep the status filter on Pending and open the TUTORIAL-B2-18 row. Verify the renter, unit, resource type, preferred date, and renter note. Also check whether another pending or approved request creates a conflict for this resource.

Add the prepared decision note and select Approve once. The drawer changes to Approved and records the decision. Approval is the point where the parking spot becomes held for this resident, so managers should complete every identity, unit, availability, and conflict check before selecting it.

Return to Ahmed’s renter account and refresh Facilities and Parking. The same request now shows Approved, and the parking card is held for Ahmed. This confirms that the manager decision reached the resident view and changed the shared inventory state.

When the resident no longer needs the allocation, select Release Spot on the approved row. Read the confirmation, then select Release Spot once more. The request changes to Released. Release preserves the request and decision history; it does not delete the record or make the previous approval disappear.

Finish as the Tenant Admin on the property’s Parking tab. Confirm that TUTORIAL-B2-18 is Available again, remains active, and has no pending request. The complete pattern is: verify inventory, submit once, review the pending request, approve deliberately, confirm the renter’s allocation, release when finished, and verify restored availability.
