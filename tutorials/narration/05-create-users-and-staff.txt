This tutorial separates application users from staff records and shows how the minimum required role and property assignment are reviewed. We are using the prepared RentAxis Tutorial Studio tenant, so no extra production account is saved during this recording.

Open Users and select New User. The form asks for a full name, email, phone, password, role, and organization. In a real onboarding, search first to avoid duplicate accounts, enter approved synthetic or customer data, and select the lowest role that covers the person’s work. A Property Manager can operate assigned properties without organization-wide control; a Tenant Admin has a much broader surface. Never expose an onboarding password in a recording or send it through an unapproved channel.

Next, open Staff Management and select Add Staff. A staff record captures employment details such as the bilingual name, employee ID, designation, department, salary, join date, phone, and assigned property. It can also be linked to a salary account. Review the Active status before saving. A staff profile represents a worker; it is separate from application login access, and creating one does not automatically create the other.

Open the prepared residence property and review its Property Manager cards. The assigned manager and the guard account are visible here, which is the property boundary that matters operationally. A manager should see assigned properties only; an unassigned record must not become reachable through a direct URL. When responsibilities change, update assignments promptly and confirm the list after saving.

Return to Users and filter for the prepared manager account. Review the email, phone, role, and tenant identifier together. Keep role changes least-privilege, do not promote a tenant user to Super Admin, and never administer another organization’s account from the wrong context. When someone leaves, deactivate access rather than sharing or recycling credentials; retain historical staff records needed for audit. These checks keep user access, staff operations, and property responsibility clearly separated.
