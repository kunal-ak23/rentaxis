This tutorial covers gate passes in Oasis Crest Properties: a Tenant invites visitors, a manager approves the regular ones, and the Company Admin sets how the gate treats walk-ins. Signed in as the Tenant Ahmed Hassan, open Gate passes and select Request pass. For a dinner guest, enter the name and mobile number, a purpose and the car's plate. Single visit is for a one-off visit: pick today, from six to eleven in the evening, and select Create pass. The pass is active at once, with a gate code to send to the guest; the guard enters it at the gate. A housekeeper who comes every week needs a Recurring pass instead. Enter her name, number and purpose, set the first and last day, and select Request pass. It waits as Awaiting approval. Now sign in as the Company Admin and open Gate pass approvals. Check the guest, unit, validity and purpose, then select Approve and confirm. Maria Santos's pass is now active. Under Policy and visitors, each property sets its access policy for walk-in visitors: whether the Tenant approves new visitors, whether a photo is required, and how long the gate waits for an answer. Below are the regular visitors registered per unit, and the guard postings that decide which properties each guard works at. Back as the Tenant, the recurring pass is now Active. Open it to see the gate code and the validity. Share the code only with the visitor it is for: anyone holding it can be let in.
