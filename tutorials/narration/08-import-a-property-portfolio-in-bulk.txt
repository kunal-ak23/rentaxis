Bulk portfolio import is intended for controlled onboarding and migration. It can create many connected records, so prepare and validate the workbook before uploading it. We are using the prepared RentAxis Tutorial Studio tenant, and this recording stops before an upload so no additional production records are created.

Open Import Portfolio from the portfolio area and download a fresh template from the running version of RentAxis. Do not reuse an old workbook because required columns and accepted values can change. The dialog identifies the supported Excel format and the expected sheets for properties, units, renters, and leases. Open the downloaded workbook outside the browser and preserve its headings and sheet names; do not insert decorative rows.

Before uploading a real migration workbook, use only approved synthetic or customer data. Keep references stable so a unit points to the correct property, a lease points to the correct renter and unit, and installment totals reconcile with the lease. Validate a deliberately invalid copy first, then correct every reported row, column, and message before attempting a real import. A validation failure must not silently create a partial portfolio.

Review the preview or import summary before confirming. Compare counts for projects, properties, buildings, units, renters, leases, and installments with the prepared source totals. Start an import once, keep the page open until completion, and never submit the same workbook again while a job is processing. After success, inspect representative records and review import history for the operator, time, source file, and result. Retain the source workbook securely for reconciliation; use normal record workflows for later corrections.
