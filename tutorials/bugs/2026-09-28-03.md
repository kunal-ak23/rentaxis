# Tenant Portal home: "Next payment AED 0 · 84 days overdue" for a cheque already at the bank

- Found by: tutorial 03 refresh (batch 1), Tenant scene; first noticed in the pilot (tutorial-pilot-report.md, concern 4).
- Stack: local recording stack (web :3004 / backend :8084, built from 15523cc), organisation Oasis Crest Properties.
- Who: Tenant Ahmed Hassan (A-101), seeded by `scripts/seed_demo_tenant.py`.
- Blocks: tutorial 03 (the Tenant scene lands on the portal home; its proof now asserts this card and fails). Also visible in any
  tutorial that shows the Tenant Portal home or My Payments for Ahmed (21, 31/32 mobile if the app uses the same feed).

## What the viewer sees

Tenant Portal home (`/en/dashboard/renter-portal`), NEXT PAYMENT card:

> NEXT PAYMENT · AED 0 · Due 01/07/2026 · badge "84 days overdue"

My Payments shows the same row as "NEXT CHEQUE · OVERDUE 0.00 … 84 DAYS OVERDUE … TOTAL PAYABLE AED 0".

A tenant is told they owe nothing and, in the same card, that they are 84 days late.

## Why

`GET /api/v1/online-payments/my-payments` returns cheque 200103 (Rent - 3rd Installment, 21,250.00, due 2026-07-01) as

```
"status":"DEPOSITED","due":true,"overdue":true,"daysOverdue":84,"payable":0
```

`OnlinePaymentService#payable` deliberately returns 0 for DEPOSITED ("the paper is at the bank and will clear there"), but
`ChequeDueRules.overdue` still flags the row overdue, and the portal's next-payment card picks the first due row regardless
of `payable`. The two rules disagree about a deposited cheque.

## Expected

A deposited cheque is not something the tenant can or should pay: either it is not "overdue" for the tenant (show it as
"At the bank / awaiting clearance"), or the next-payment card skips rows with `payable == 0` and shows the next
collectable instalment (or "Nothing due").

Related, landlord side (not blocking): Home › Needs you now › Overdue payments lists the same deposited cheque
(A-101 · Ahmed Hassan · #200103, AED 21,250). Whether a cheque deposited 84 days ago without clearing belongs there is a
product decision; the seed leaves it DEPOSITED.
