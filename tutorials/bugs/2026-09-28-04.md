# Organisation switcher does not list an organisation provisioned in the same page session

- Found by: tutorial 04 refresh (batch 1).
- Stack: local recording stack (web :3004 / backend :8084, built from 15523cc).
- Severity: low (UX). Not blocking 04: the tutorial's switch scene starts on a freshly loaded page, like every scene that
  is not a `stepScene`. Flagged so the coordinator can decide whether that counts as scripting around it.

## Steps

1. System Admin → Settings › Administration › Organisations.
2. Provision New Organisation → name "Palm Vista Real Estate" → Create Organisation. The row appears in the table.
3. Without reloading, open the organisation switcher (top of the side panel) and type "Palm".

## Actual

"No matching organizations". The switcher's list was fetched when the shell mounted and is not refreshed after the
create; only a full page load shows the new organisation.

## Expected

The switcher lists the new organisation straight away (refetch after a create/edit/delete on the Organisations page, or
fetch when the switcher opens).

Side notes seen on the same page (copy, not blocking): the switcher placeholder and empty state say "organizations"
(US spelling) while the page says "Organisations"; the delete dialog says "Delete organization"; the Feature Toggles
drawer still labels a feature "Lease Renewals & Reminders"; the name field's placeholder is a real company
("e.g. Al Futtaim Properties").

Also on the Organisations page: a search with no match shows the empty state "No organisations provisioned yet.", which is
wrong when organisations exist (it should read "No organisations match your search").
