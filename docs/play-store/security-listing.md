## English (en-GB)

### Short description

Scan passes, manage arrivals and keep residential gate access moving safely.

### Full description

Smarter access at the gate.

Miftah Security is designed for authorised residential security teams. It puts assigned properties, expected visitors and access decisions into one focused mobile workflow.

With Miftah Security you can:

• Sign in securely with an assigned guard phone number
• View assigned properties and visitors expected today
• Scan a visitor-pass QR code or enter its numeric code
• See a clear allowed or rejected result with guest, vehicle, unit and validity details
• Review approval queues for controlled visitor access
• Capture walk-in visitor details and a supporting photo
• Follow resident approval status and admit an approved visitor
• Switch between English and Arabic

Miftah Security requires an active security-guard account assigned by a participating property organisation. A camera is used for QR scanning and optional visitor photos; numeric code entry is also available. Access outcomes are based on the property’s current passes, policies and approvals.

### Release notes

The first Google Play release of Miftah Security brings assigned-property visitor boards, QR and numeric pass validation, clear gate verdicts, approval queues and managed walk-in admission to authorised security teams.
